# Jolie-Ni/homebrew-tap

Homebrew tap for [DeskMate](https://github.com/Jolie-Ni/DeskMate).

```sh
brew install --cask jolie-ni/tap/deskmate
```

Builds are signed with a Developer ID certificate and notarized by Apple, so the
app opens on a double-click with no security dialog and no `xattr` workaround.
